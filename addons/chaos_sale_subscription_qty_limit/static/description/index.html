Sale Subscription Quantity Limit

Control quantity limits for subscription upsell products

Odoo 18 JavaScript Portal

Overview

This module provides smart quantity limiting for specific subscription upsell products in the customer portal. It prevents customers from ordering more than 1 unit of designated products, ensuring compliance with your business rules for add-on services and special items.

Key Features

🎯 Automatic Detection

Automatically identifies products based on trazet_product_key values

🔒 Quantity Enforcement

Enforces maximum quantity of 1 for targeted subscription products

🎨 UI Feedback

Disables increment button and shows visual feedback when limit is reached

⚡ Input Validation

Prevents manual quantity input above the allowed limit

💬 User Notifications

Displays clear warning messages when users attempt to exceed limits

🔄 Dynamic Updates

Uses MutationObserver to handle AJAX-loaded content

Targeted Products

The module limits quantity to 1 for products with these trazet_product_key values:

  • allowExternalAPI - External API access products
  • collectPeriod - Data collection period products

How It Works

Template Layer

Extends the sale.sale_order_portal_content template to add data attributes (data-product-key) to order line rows. This allows JavaScript to identify which products need quantity limiting.

JavaScript Layer

Pure JavaScript implementation that:

  • Monitors order line quantity inputs and buttons
  • Intercepts increment button clicks
  • Validates manual input changes
  • Shows user-friendly warning messages
  • Works with dynamic content updates
