# Required Images for Odoo Apps Store

This module needs the following images for the Odoo Apps Store listing:

## Icon (Required)
**File:** `icon.png`
**Size:** 256x256 pixels
**Format:** PNG with transparency
**Description:** Module icon displayed in the Apps list

## Banner (Required)
**File:** `banner.png`
**Size:** 1200x300 pixels (recommended)
**Format:** PNG or JPG
**Description:** Main banner image for the module page

## Screenshots (Recommended)

### 1. Configuration Screenshot
**File:** `screenshot_config.png`
**Size:** 1280x720 pixels (recommended)
**Description:** Show the configuration checkbox in POS Settings (Bills & Receipts section)

### 2. Receipt Comparison
**File:** `screenshot_receipt_comparison.png`
**Size:** 1280x720 pixels (recommended)
**Description:** Side-by-side comparison of receipt with taxes shown vs taxes hidden

### 3. Settings Location
**File:** `screenshot_settings.png`
**Size:** 1280x720 pixels (recommended)
**Description:** Show how to navigate to the setting (Point of Sale → Configuration → Settings)

## Design Guidelines

- Use consistent colors (#875A7B for primary purple color - Odoo's default)
- Include clear labels and arrows pointing to important elements
- Use high-resolution images (at least 1280px wide for screenshots)
- Ensure text is readable when scaled down
- Use actual Odoo UI screenshots when possible

## Tools for Creating Images

- **Icon:** Use tools like GIMP, Photoshop, or online tools like Canva
- **Screenshots:** Use Odoo's built-in UI with a screenshot tool
- **Banner:** Create in Canva, Figma, or Photoshop

## Notes

- All images should be optimized for web (compress to reduce file size)
- PNG format preferred for transparency support
- For the Apps Store submission, these images are REQUIRED
- The module will install without images, but they're needed for publishing
