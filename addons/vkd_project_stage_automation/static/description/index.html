🤖 Project Stage Automation

Automatically transition tasks between stages based on configurable rules with full project template support.

✅ Template Support 🎯 Condition-Based ⚡ Automatic 🔄 Flexible

✨ Key Features

📋 Project Template Support

Configure automation rules once on a project template. All projects created from that template automatically inherit the rules!

🎯 Multiple Condition Types

Always execute, all subtasks done, dependencies complete, percentage-based, and more.

🚀 Multiple Action Types

Move to stage, set task state, or perform both actions simultaneously.

📊 Execution Tracking

Monitor how many times each rule has been executed and when it last ran.

💡 Use Cases

Development Workflow: Automatically move task to "Testing" when all development subtasks are completed.
Quality Assurance: Mark task as Done when 100% of test subtasks are complete.
Dependency Management: Resume work automatically when blocking dependencies are resolved.
Template Consistency: Ensure all projects from the same template follow identical automation workflows.

🎨 How It Works

  1. Trigger: Task enters a specific stage
  2. Condition: System checks if requirements are met
  3. Action: If conditions met, automatically perform action
  4. Notification: Message posted in task chatter

⚙️ Configuration

On Project Template:

  1. Go to Project → Configuration → Projects
  2. Open a project template
  3. Navigate to "Stage Automation" tab
  4. Add your automation rules
  5. All projects created from this template will inherit the rules!

On Individual Project:

  1. Open any project
  2. Go to "Stage Automation" tab
  3. Configure rules specific to that project

Global Management:

  1. Go to Project → Configuration → Stage Automation
  2. View and manage all automation rules
  3. Filter and organize by project or condition type
